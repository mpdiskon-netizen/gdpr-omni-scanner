# Licences, datasets and attribution

This file records the principal external software, models and evaluation datasets used by the project. It is an attribution record for a university prototype, not legal advice. Full dependency licences remain available from their original packages and projects.

## Runtime software and models

| Component | Project use | Licence / attribution source |
|---|---|---|
| spaCy and `en_core_web_sm` | English person and location recognition | MIT; <https://github.com/explosion/spaCy> and <https://github.com/explosion/spacy-models> |
| Tesseract OCR and English trained data | Printed-English OCR | Apache License 2.0; <https://github.com/tesseract-ocr/tesseract> |
| OpenAI Whisper `tiny.en` | Offline English speech transcription | Code and model weights released under MIT; <https://github.com/openai/whisper> |
| FFmpeg | Audio decoding required by Whisper | Licence depends on the selected build configuration; <https://ffmpeg.org/legal.html> |
| Pillow | Image loading and conversion | See the Pillow package licence; <https://github.com/python-pillow/Pillow> |
| pytesseract | Python adapter for local Tesseract | Apache License 2.0; <https://github.com/madmaze/pytesseract> |
| EasyOCR 1.7.2 | Optional comparison only; not the selected application OCR model | Apache License 2.0; <https://github.com/JaidedAI/EasyOCR> |

The release archive contains project source and small synthetic samples. It does not bundle the Tesseract executable, FFmpeg, spaCy model, Whisper model weights, EasyOCR weights or their transitive dependencies.

## Evaluation datasets

| Dataset | Use in this project | Handling and required attribution |
|---|---|---|
| Enron email corpus | Ten-message, model-assisted and human-corrected text-detection pilot | Downloaded and processed only on the student's machine. Raw messages and labels are excluded from the release. Cite the actual corpus distribution used and describe the privacy safeguards. |
| AMI Meeting Corpus | Whisper word-error-rate evaluation and `tiny.en`/`base.en` comparison | AMI signals and transcriptions are available under CC BY 4.0. Credit the AMI project and cite the corpus site: <https://groups.inf.ed.ac.uk/ami/corpus/>. Raw clips are excluded from the release. |
| FUNSD | Tesseract/EasyOCR character-error-rate evaluation on noisy scanned forms | Non-commercial research and educational use only. Do not redistribute the images. Cite Jaume, Ekenel and Thiran (2019) and the official terms: <https://guillaumejaume.github.io/FUNSD/work/>. |
| Controlled corporate image set | OCR and end-to-end finding evaluation on badges, notes and corporate-style documents | Generated by this project using fictional data. The generator, manifest, provenance and images are included so the result can be reproduced. It supplements FUNSD and is not described as representative real-world data. |
